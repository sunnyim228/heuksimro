# 앱인토스 등록에 넣을 내용

콘솔 칸에 그대로 복사해 넣을 수 있게 정리했어요. 글자 수 제한에 걸리면 짧은 판을 쓰세요.

## 1. 앱 만들기 (첫 화면)

| 칸 | 넣을 내용 |
| --- | --- |
| 어떤 앱을 만들고 싶나요? | 할머니의 식당을 물려받아 요리하고 손님을 대접하는 힐링 요리 게임 |
| 앱 이름 | 모락모락 식당 |
| appName | morakmorak |
| 앱 유형 | 게임 |

- **앱 이름**: "모락모락"만 쓰면 비슷한 이름이 이미 있다고 나와요. "모락모락 식당"처럼 한 단어를 붙이면 찾기 쉬워요. 그대로 "모락모락"으로 해도 등록은 돼요.
- **appName**: 한 번 정하면 바꿀 수 없어요. 올릴 묶음 파일(`morakmorak.ait`)이 이 이름으로 만들어져 있으니 **반드시 `morakmorak`** 으로 넣으세요. 이미 누가 쓰고 있어서 안 되면 `morakmorak-game` 처럼 바꾸고 알려 주세요. 묶음 파일을 그 이름으로 다시 만들어야 해요.

## 2. 한 줄 소개 (택 1)

| 방향 | 문구 |
| --- | --- |
| 위로 (권장) | 지친 하루 끝에, 따뜻한 밥 한 그릇 차려 주는 게임 |
| 차별점 | 주문 말고 사정을 듣고, 딱 맞는 한 그릇을 내어 주세요 |
| 이야기 | 할머니가 남긴 식당, 뜯겨 나간 레시피를 한 그릇씩 되찾아요 |

## 3. 상세 설명

글자 수 제한에 걸리면 ■ 다섯 덩어리 중 앞의 세 개만 남기세요.

```
"요즘 뭘 먹어도 맛이 없다" 싶은 날, 이 식당 문을 열어 보세요.

■ 실패가 없어요
음식이 타지도, 가게가 망하지도 않아요. 서두르라고 재촉하는 타이머도 없어요.
잠깐 짬이 날 때 한 판, 편하게 하면 돼요.
자리를 비운 사이에도 장독은 익고 텃밭은 자라요. 돌아오면 반겨 줘요.

■ 주문이 아니라 사람을 봐요
"감기 기운이 있어요." "오늘 좀 울적해서요."
손님은 메뉴 이름 대신 사정을 말해요. 얼굴을 보고 딱 맞는 한 그릇을 골라 주면,
"딱 이게 필요했어요" 하는 한마디가 돌아와요.

■ 나부터 잘 먹어야 해요
이 게임의 요리사는 자기 끼니도 챙겨야 해요.
잘 먹고 잘 쉬면 손맛이 살아나고, 거르면 간이 안 맞아요.
게임을 하다 보면 "나 오늘 밥은 먹었나?" 하고 돌아보게 돼요.

■ 한 그릇마다 이야기가 열려요
할머니는 레시피를 마을 사람들에게 한 장씩 맡겨 두고 떠났어요.
대접하고, 같이 밥을 먹을수록 사람들이 속 얘기를 들려줘요.
삼십 년 전 끊긴 국밥 한 그릇의 사연, 끝까지 보면 누군가에게 전화하고 싶어질 거예요.

■ 내 이름을 건 메뉴
재료를 골라 나만의 요리를 짓고, 식탁과 화구를 늘려 가게를 키워요.
텃밭, 숲, 바닷가, 버스 타고 가는 옆 마을까지. 재료를 구하러 다니는 재미도 있어요.

이런 분께 권해요
· 경쟁하고 쫓기는 게임에 지친 분
· 따뜻한 이야기가 있는 게임을 찾는 분
· 요리, 식당 운영, 아기자기한 픽셀 그림을 좋아하는 분
```

| 항목 | 이 게임 |
| --- | --- |
| 폭력·공포 | 없음 |
| 선정성 | 없음 |
| 언어 | 욕설·비속어 없음 |
| 약물·음주·흡연 | 직접 묘사 없음 (대사에 '과음' 언급 1회) |
| 사행성 | 없음. 확률형 아이템·뽑기 없음 |

| 게임 속 돈 | 가상의 '닢'. 예금·대출·이자가 나오지만 실제 금융과 연결되지 않음 |
