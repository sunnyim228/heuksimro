# 앱인토스 등록에 넣을 내용

콘솔 칸에 그대로 복사해 넣을 수 있게 정리했어요. 글자 수 제한에 걸리면 짧은 판을 쓰세요.

## 1. 앱 만들기 (첫 화면)

| 칸 | 넣을 내용 |
| --- | --- |
| 어떤 앱을 만들고 싶나요? | 할머니의 식당을 물려받아 요리하고 손님을 대접하는 힐링 요리 게임 |
| 앱 이름 | 모락모락 식당 |
| appName | `morak-sikdang` (안 되면 아래 2순위, 3순위) |
| 앱 유형 | 게임 |

**appName과 올릴 파일은 짝이 맞아야 해요.** `morakmorak`은 이미 쓰이고 있어서, 후보 3개로 묶음을 미리 만들어 두었어요. 콘솔에서 받아 준 이름의 파일을 올리세요.

| 순위 | appName | 올릴 파일 |
| --- | --- | --- |
| 1 | `morak-sikdang` | `store/toss/morak-sikdang.ait` |
| 2 | `sotgol-sikdang` | `store/toss/sotgol-sikdang.ait` |
| 3 | `morakmorak-cooking` | `store/toss/morakmorak-cooking.ait` |

셋 다 이미 쓰이고 있으면 원하는 이름을 알려 주세요. 그 이름으로 다시 만들어 드려요.

### 상세 설명 (콘솔 칸용, 450자 / 제한 500자)

콘솔 안내("무엇을 보고, 어떤 버튼을 누르고, 무엇을 경험하는지")에 맞춰 쓴 판이에요. 아래 3번의 '해야 하는 이유' 판은 홍보용으로 남겨 둬요.

```
할머니가 남긴 시골 식당을 다시 열어 손님에게 밥을 지어 대접하는 힐링 요리 게임이에요.

[낮] 화면을 눌러 걸어 다니며 텃밭에서 파·무·감자를 뽑고, 숲에서 버섯을, 바닷가에서 조개와 미역을 주워요. 부두에서는 낚시도 해요.

[저녁] 선반에서 재료를 꺼내 도마에서 손질하고 팬이나 냄비에 넣어 요리해요. 문 옆 팻말을 누르면 영업 시작. 손님이 말풍선으로 주문하면 요리를 들고 식탁을 눌러 대접해요. "감기 기운이 있어요"처럼 사정을 말하는 손님에게는 어울리는 한 그릇을 골라 줘요.

[이야기] 마을 사람에게 한 그릇씩 대접하며 할머니가 맡겨 둔 레시피를 돌려받고, 30년 전 끊긴 국밥의 사연을 알게 돼요.

[성장] 번 돈으로 식탁과 화구를 늘리고, 나만의 요리를 지어 메뉴에 올려요.

음식이 타거나 가게가 망하는 일은 없어요. 자리를 비운 사이에도 텃밭은 자라고, 진행은 자동으로 저장돼요.
```

## 3. 상세 설명

글자 수 제한에 걸리면 ■ 다섯 덩어리 중 앞의 세 개만 남기세요.

```
"요즘 뭘 먹어도 맛이 없다" 싶은 날, 이 식당 문을 열어 보세요.

■ 실패가 없어요
음식이 타지도, 가게가 망하지도 않아요. 서두르라고 재촉하는 타이머도 없어요.
잠깐 짬이 날 때 한 판, 편하게 하면 돼요.
자리를 비운 사이에도 장독은 익고 텃밭은 자라요. 돌아오면 반겨 줘요.

■ 주문이 아니라 사람을 봐요
"감기 기운이 있어요." "오늘 좀 울적해서요."
손님은 메뉴 이름 대신 사정을 말해요. 얼굴을 보고 딱 맞는 한 그릇을 골라 주면,
"딱 이게 필요했어요" 하는 한마디가 돌아와요.

■ 나부터 잘 먹어야 해요
이 게임의 요리사는 자기 끼니도 챙겨야 해요.
잘 먹고 잘 쉬면 손맛이 살아나고, 거르면 간이 안 맞아요.
게임을 하다 보면 "나 오늘 밥은 먹었나?" 하고 돌아보게 돼요.

■ 한 그릇마다 이야기가 열려요
할머니는 레시피를 마을 사람들에게 한 장씩 맡겨 두고 떠났어요.
대접하고, 같이 밥을 먹을수록 사람들이 속 얘기를 들려줘요.
삼십 년 전 끊긴 국밥 한 그릇의 사연, 끝까지 보면 누군가에게 전화하고 싶어질 거예요.

■ 내 이름을 건 메뉴
재료를 골라 나만의 요리를 짓고, 식탁과 화구를 늘려 가게를 키워요.
텃밭, 숲, 바닷가, 버스 타고 가는 옆 마을까지. 재료를 구하러 다니는 재미도 있어요.

이런 분께 권해요
· 경쟁하고 쫓기는 게임에 지친 분
· 따뜻한 이야기가 있는 게임을 찾는 분
· 요리, 식당 운영, 아기자기한 픽셀 그림을 좋아하는 분
```
